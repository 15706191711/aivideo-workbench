# aivideo-workbench

AI视频创作项目可视化工作台 Skill。

## 安装

```bash
npx -y skills add 15706191711/aivideo-workbench
```

## 功能

进入任何AI视频/短剧/AIGC短片创作项目时，自动在项目根目录生成一个自包含HTML工作台：

- **多版本切换**（V1/V2...）
- **阶段进度条**：剧本→资产→分镜→首帧→视频→成片
- **剧本正文内嵌**
- **资产库**：人物/场景/道具/首帧网格，点图放大
- **分镜表**：每行挂关联资产缩略图
- **亮色/暗色主题切换**
- **响应式**：小屏幕自动折叠侧边栏

## 使用

在AI视频项目目录下，让AI说"生成工作台"即可。每次生成资产、改分镜、推进阶段后，自动更新HTML。
